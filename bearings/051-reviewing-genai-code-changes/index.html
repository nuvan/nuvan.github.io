Are you still looking for Wallys in your code?

Reviewing code leveraging GenAI changes the process. The review shifts left to the developer and the agent that produced the code, while the developer still owns accountability.

We are not used to this. Until now, much of that responsibility was tacit, distributed, and usually exercised naively.

The post focuses on one step of the dev process, code review, but the idea generalizes easily to the whole thing, especially if you are working with a software factory pipeline, whether your lights are on or not.
