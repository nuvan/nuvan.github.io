Bearing

02 October 2026 · 19:32

Kiro shipped workflows. You describe the task, the model lays out a graph of agent steps with loops and parallel branches, and the runtime runs it instead of you typing “now review that” every ten minutes.

Each step gets its own session with fresh context. The reviewer never sees the coder’s reasoning, only its output. Cloudflare built the same rule into their security audit skill, where the agent that verifies a finding is never the agent that found it.

One of the bundled recipes, investigate, exists only to run a read-only investigation somewhere else and keep its tool output out of your main conversation. That tells you what they think the bottleneck is.

They built most of the workflow runtime using workflows, each implementation run isolated in its own Git worktree. Dozens per session, five to ten steps each, going nearly 24/7 across the team.

It is opt-in. Credits scale with whatever work it decides the task needs, so an auto-generated workflow can cost more than the one you would have written.
